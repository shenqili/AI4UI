# 本期复刻提示词 · 一物一控

根据实际创作过程整理。工程中的效果按时间线演示；若要做成可操作控件，请明确要求接入真实输入与状态。

## 1. 单场景基础提示词

```text
请实现一个“日常物件变成 UI 控件”的完整浏览器场景。
先选择一个物件和一种明确的控件语义，说明用户做什么动作、数值怎样改变、完成状态是什么。
用 HTML、CSS、JavaScript、Canvas 2D 实现，保持视觉和状态逻辑分离。
以进度 p（0–1）统一驱动物件姿态、读数、材质和对应的标准控件示意。
先给出 p=0、0.5、1 三个可检查状态，再加入完整动作。
主体有统一光源、接触阴影和清楚的结构；会动的零件单独绘制，不用一张整图冒充关节。
保持背景、镜头、画布和固定边缘稳定，变化发生在物件内部。刚性物体到位即停；软体允许小幅、逐渐衰减的变形。
用读数、标签或明确的结果态解释功能，不能只有好看但看不出用途的动作。
提供完整可运行文件、操作说明与资源清单，不依赖私有路径、密钥或付费服务才能预览。
```

## 2. 选择一个场景方向

| 物件 | 追加到基础提示词的方向 |
| --- | --- |
| 布丁开关 | 用布丁的柔软形变表达开关切换，盘子与接触点固定；背景与右上角 Toggle 跟随同一个状态。 |
| 像素房间滑块 | 把房间放进透明胶囊，滑块从左向右时人物由休息转为活动，扬声器声波增强；始终明确这是音量。 |
| 图章复选框 | 三个方框对应三次盖章，每次印出清楚的勾；纸张位置固定，完成结果保留，不做全屏震动。 |
| 折扇下拉 | 用展开的扇骨承载菜单条目，展开、选中、合拢有明确的层次；扇面水墨保持整体画面连贯。 |
| 收音机旋钮 | 指针和大号频点读数一起变化，接近频点后锁定，指示灯变绿；高光保持固定光源。 |
| 沙山进度 | 沙粒落下形成堆积，百分比和进度轨道同步；到 100% 停止落沙并保留结果态。 |
| 索引卡盒 Tabs | 卡片被选中后从卡盒中抬起，内容跟随选项切换；每次只强调一个选中项，避免所有卡片同时运动。 |
| 透镜取色 | 灰度画面中透镜露出彩色内容；取到的色片进入托盘，并显示与色块一致的十六进制色值。 |
| 卷帘刷新 | 下拉卷帘积蓄动作，释放后回位并更新窗景；用明确的 Refreshed 状态说明刷新已完成。 |
| 风车加载 | 风推动纸瓣旋转；停止后纸瓣聚拢，以保留的三点加载标记使功能可识别。 |
| 萤火罐评分 | 萤火虫逐个进入罐中，标准星级同步点亮，一次完整评分过程结束后保留最终数量。 |
| 邮筒上传 | 信封进入邮筒时进度增长，完成后吐出带印章的“已送达”回执；回执必须有足够停留时间读清。 |

## 3. 做成视频同款确定性场景

```text
请沿用 film/engine.js 的接口，只实现指定场景文件。
Film.scene(id, { mount(root, {W,H}), render(c) })。
mount 中创建画布、缓存纹理并预生成有种子的随机数组；render 根据 c.p、c.drag、c.t、c.ev 直接绘制当前帧。
动作时点从 cues 读取，不在场景内部维护另一条时间线。
同一时刻重复或乱序渲染，结果应相同。不要在 render 内调用 Math.random、推进粒子状态、读取真实时钟。
支持 forced 完成态：即使没有事件列表，也能用 p=1、drag=1、flipAge=9 显示可读结果。
在 1920×1080 和缩略图中都检查功能识别、文字对比度及右上角控件标示的遮挡。
```

## 4. 从演示转为真实交互

```text
请把指定 Canvas 场景转换为真正可操作的控件。
保留已有绘制函数，把 p 的来源从录制时间线替换为真实应用状态。
支持 Pointer Events、触屏、键盘和可见焦点；用语义化 HTML 输入维护 aria-checked 或 aria-valuenow。
先实现一次完整交互，再补快速反向、拖出边界、取消、窗口缩放和减少动态效果偏好。
上传组件必须以真实网络回调和服务端结果为准，分别表达发送、处理、失败、重试和完成；不要用计时器伪造成功。
请说明还需由业务层接入的回调，并输出完整代码。
```

## 5. 评审与收敛

```text
请逐项检查：
1. 不看文字时，能否识别物件；看一眼标签后，能否理解控件用途？
2. 数值、物件、标准控件三者是否由同一状态驱动？
3. 操作前、中、后是否连续，结果是否停留至少两拍？
4. 固定背景或刚体是否被多余的弹跳、位移、缩放破坏？
5. 大读数、色值、完成回执在手机尺寸是否可读，是否被标示遮挡？
6. 删除一个装饰后，功能是否反而更清楚？
先指出影响识别和可用性的三个主要问题，再逐项修改并对照相同时间点检查。
```

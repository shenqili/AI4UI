# AI4UI · 把开关玩出花

用 Claude 辅助复刻创意明暗交互，再通过提示词迭代材质、光线与动效。

这是本次 Toggle Lab 项目的**精简交互学习版**：一个 HTML 文件，五个代表性案例。无需安装依赖，双击 `index.html` 即可运行。

| 案例 | 交互 | 学习重点 |
| --- | --- | --- |
| Glass | 点击 / 拖动玻璃开关，切换强调色 | 透光、高光、背景与按钮层次 |
| Lamp | 拖动开关，改变房间灯光和仪表盘状态 | 多个视觉元素跟随同一个状态 |
| Reading | 切换阅读界面主题，点击收藏 | 内容层级、卡片材质、可操作细节 |
| Landscape | 拖动日夜滑轨 | SVG 远近层次、日月与湖面联动 |
| Kelvin | 连续拖动色温滑轨 | 连续数值、暖冷光与界面主题联动 |

顶部导航或数字键 `1–5` 切换场景。也可以用左右方向键切换；聚焦开关后，按其提示使用方向键、空格或 Enter。

## 从哪里开始

1. 打开 [`index.html`](index.html)，先体验五个案例。
2. 复制 [`PROMPTS.md`](PROMPTS.md) 的基础提示词，让 Claude 生成自己的第一个组件。
3. 按 [`TUTORIAL.md`](TUTORIAL.md) 的步骤检查结构、交互与动效，再逐轮细化。

源码约 44 KB，包含 HTML、CSS、JavaScript 和内联 SVG，不需要框架、图片下载或 API Key。
